# Changelog

## v1.0.1

- Fixed a crash when opening the Bows tab on a save with no bows in the inventory.
- Restored arrow editing on the Bows tab (an Arrows tile for viewing and editing your arrow count).
- Added an in-app updater: ToTK Save Editor checks for new releases on launch and can download and install them from the About tab.

## v1.0.0

Initial release of ToTK Save Editor for Nintendo Switch homebrew.
